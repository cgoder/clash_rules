# 订阅节点分组验证脚本

## 脚本说明

`validate_subscription.sh` - 完整的订阅节点分组检测脚本

### 功能

该脚本会：
1. 下载指定的订阅链接
2. 提取所有真实节点（排除策略组）
3. 统计各国家/地区的节点分布
4. 从配置文件中提取过滤器
5. 按策略分组并统计节点数量
6. 检测是否有节点未被正确分配

### 使用方法

```bash
./validate_subscription.sh <订阅URL>
```

### 示例

```bash
# 验证你的订阅
./validate_subscription.sh "https://your-provider.com/sub.yaml?token=YOUR_TOKEN"
```

### 注意事项

⚠️ **关于"未匹配"的说明**

由于 bash 的 `grep -E` 不完全支持 Clash 使用的正则语法（正向预查 `(?=...)`），脚本可能会报告少量节点"未匹配"。这是**测试工具的局限性**，不代表实际配置有问题。

**真正的验证方法是在 Clash 应用中实际测试！**

### 配置文件位置

脚本会读取配置文件：`C:/Users/tienchiu/code/github/clash_rules/clashmi.yml`

如果配置文件位置不同，请修改脚本中的 `CONFIG` 变量。

### 依赖

- bash
- curl
- grep, sed, awk（标准Unix工具）

### 故障排除

1. **订阅下载失败**
   - 检查URL是否正确
   - 检查网络连接
   - 确认订阅token是否有效

2. **提取节点数为0**
   - 订阅格式可能不是标准的Clash配置
   - 检查订阅内容是否包含 `- name:` 字段

3. **配置文件未找到**
   - 确认 `clashmi.yml` 路径正确
   - 修改脚本中的 `CONFIG` 变量指向正确路径
