### 3️⃣ 针对不稳定的优化

```yaml
Anchor_LB:
  interval: 120          # 2分钟检测（比标准300秒快2.5倍）
  timeout: 1500          # 1.5秒超时（比标准2秒快25%）
  max-failed-times: 2    # 2次失败即剔除（比标准3次快33%）
  lazy: false            # 主动检测，不惰性
```

## 🔧 高级调优

### 如果节点极度不稳定

修改 `Anchor_LB` 参数：
```yaml
interval: 60             # 1分钟检测（更激进）
timeout: 1000            # 1秒超时（更快判断）
max-failed-times: 1      # 1次失败即剔除（最激进）
```

### 如果想要更平均的分配

改用 round-robin 策略：
```yaml
strategy: round-robin    # 绝对轮询（不考虑域名）
```
