## 🔧 配置特性

### 当前配置 (clashmi.yml) 特点
- ✅ 常用地区负载均衡（HK/TW/SG/JP/US）
- ✅ 地理分组手动选择（亚洲/欧洲/美洲/其他）
- ✅ AI 服务独立分组（ChatGPT/Claude/Gemini）
- ✅ 场景化服务分组（流媒体/通信/云服务/金融）
- ✅ DNS 防污染和防泄漏
- ✅ 自动过滤无效节点

### 配置版本历史
| 版本 | 特点 | 状态 |
|------|------|------|
| v4 | 场景化分组，简化配置 | ✅ 当前生产版本 |
| v3 | 完整功能，移除冗余 DNS | ✅ 可用 |
| v2 | 修复 DNS 死锁问题 | ⚠️ 已被 v3 替代 |
| v1 | 初始防泄漏方案 | ❌ 存在 DNS 死锁 |
