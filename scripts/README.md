# Scripts 工具脚本

本目录包含 Clash 配置相关的实用脚本。

## 📁 脚本清单

### validate_subscription.sh
**功能**：验证订阅节点分组完整性

**用法**：
```bash
./validate_subscription.sh <订阅URL>
```

**功能详解**：
1. 下载订阅数据
2. 提取真实节点（排除信息行）
3. 统计国家/地区分布
4. 验证节点分组是否完整
5. 检测未匹配节点

**输出报告**：
- 总节点数统计
- 各地区节点分布
- 各策略组节点数量
- 未匹配节点列表（如有）

**适用场景**：
- 验证配置是否覆盖所有节点
- 检查过滤器规则是否正确
- 订阅更新后的完整性检查

---

## 🛠️ 使用说明

### 环境要求
- Bash shell
- curl（下载订阅）
- grep、sed、awk（文本处理）
- 可选：rtk（Rust Token Killer，用于代理下载）

### 权限设置
```bash
chmod +x validate_subscription.sh
```

### 示例用法
```bash
# 验证订阅
./validate_subscription.sh "https://your-subscription-url"

# 查看完整报告
./validate_subscription.sh "https://your-subscription-url" | tee report.txt
```

## 🔧 脚本维护

### 添加新的地区过滤器

如需添加新地区检测，修改脚本中的国家识别部分：

```bash
# 在脚本中找到 country 识别段落
if [[ "$node" =~ 美国|🇺🇸|US|USA ]]; then country="US"
elif [[ "$node" =~ 香港|🇭🇰|HKG|HK ]]; then country="HK"
# ... 添加新地区
elif [[ "$node" =~ 你的地区|🇫🇴|FLAG ]]; then country="NEW"
```

### 配置文件路径

脚本默认读取配置文件路径：
```bash
CONFIG="C:/Users/tienchiu/code/github/clash_rules/clashmi.yml"
```

如需修改，编辑脚本中的 `CONFIG` 变量。

## 📝 注意事项

1. **订阅 URL 安全**
   - 避免在公共环境运行
   - 订阅 URL 包含敏感信息，注意保密

2. **代理下载**
   - 脚本使用 `rtk proxy curl` 下载订阅
   - 如未安装 rtk，改为 `curl`

3. **临时文件**
   - 脚本在 `/tmp` 目录生成临时文件
   - 执行完毕后可手动清理

4. **配置文件同步**
   - 确保脚本读取的配置文件是最新版本
   - 修改过滤器后重新验证
